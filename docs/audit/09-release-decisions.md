# Release decisions and privacy review

Reviewed on 2026-11-22. This record uses aggregate results and code paths. The rehearsal inputs were synthetic or controlled public-site fixtures. Hosted evidence and physical-microphone verification remain open.

## Privacy boundaries

| Boundary | Decision and observed evidence |
|---|---|
| Accounts and saved projects | The signed-in owner is checked before reading a project, job, uploaded source or host artifact. Login tokens are hashed server-side, the production cookie is HTTP-only and secure, and import revokes the legacy session credential within the ownership transaction. The independent account, audience, presentation, deck, upload and capture fixture run passed 15 tests and 277 assertions. It exercised owner reopen and access denial. [Account middleware](../../backend/src/middleware/account.ts) · [Session authorization](../../backend/src/middleware/host-session.ts) · [Import transaction](../../backend/src/repositories/accounts.ts) |
| Audience output and offline HTML | Public slide footers use `Supplied material` for uploaded evidence and the hostname for a public source. Same-screen fullscreen shows the approved stage. Audience responses project approved slide text and chart values without internal evidence IDs, host notes, narration or file names. Chrome opened offline HTML at 1280×720, 1440×900 and 390×844 and verified that the screenshot was embedded and its private URL was absent. [Shared source labels](../../shared/presentation.ts) · [Audience projection](../../backend/src/repositories/audience.ts) · [HTML privacy regression](../../scripts/check-html-deck.ts) |
| Host exports | `context.md` and `plan.json` stay owner-scoped and uncached. They intentionally carry research excerpts, source references, and, for the plan, narration. The offline HTML is the shareable slide export, whose visible text still needs host review before sharing. ## Open privacy checks

- Files-only governs retrieval. Configured models may still receive saved brief text and eligible excerpts. Where configured, the Site agent model makes navigation decisions using the approved scope and page observations. The PowerPoint selection exporter uses the confirmed scope locally. Provider retention for the Decisions endpoint remains unverified before hosted use with sensitive input. [Decisions request](../../backend/src/services/presentation-readiness.ts) · [Site agent](../../backend/src/services/site-agent.ts) · [PowerPoint export](../../backend/src/services/walkthrough-selection.ts)
- An independent mocked provider reproduced a private-note identifier reaching the search request. The dispatch now blocks matching identifiers and unapproved distinctive verbatim excerpts. The retest sent only the ordinary public query to the mock. Paraphrased sensitive information remains an open privacy risk. [Search dispatcher](../../backend/src/services/research-tools.ts) · [Dispatch regression](../../backend/tests/research-tools.test.ts)
- The sign-out cleanup now removes colon- and dot-prefixed project receipts from the tab. A local storage fixture retained unrelated values and the theme selection remains in separate local storage. [Account cleanup](../../frontend/lib/projects.ts)
- An investigation printed an isolated preview voice token in a diagnostic. The test credential was rotated, both isolated services were refreshed, and a local request confirmed the new token reached request validation while an invalid token was denied. The test stopped before contacting a provider.
