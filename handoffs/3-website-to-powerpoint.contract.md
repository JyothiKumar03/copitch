# Contract: Website to PowerPoint (module 3)

Owner decisions pending: The owner will deploy to AWS after accepting the local result. Run the deployed smoke against the owner’s release target when available.

Source: Owner requests for website-to-PowerPoint and explicit export selection, the private project entry at `/research`, `backend/src/routes/website-walkthrough.ts`, `backend/src/routes/site-run.ts`, and `docs/orchestration.md`.

A signed-in host opens a saved walkthrough, chooses the exact captured content that belongs in a PowerPoint, confirms the selection, and can download the same saved export after signing in again.

| ID | Actor action | Observable outcome | Check (entry point + exact command or click path) | Required evidence |
|----|--------------|--------------------|---------------------------------------------------|-------------------|
| AC-1 | Signed-in host adds a public website to a private project | The host can set the starting URL, audience, presentation goal and crawl depth and review them before starting. | AC-2 | Host approves exploration of a public site | A bounded Playwright browser opens the approved origin and follows eligible, visible same-origin navigation. | AC-3 | Host opens a PowerPoint from a completed walkthrough | Archived PowerPoint artifacts keep their original bytes, including any original cover, captured links or coverage slides. | AC-6 | Host runs the full workflow on the AWS deployment | The deployed HTTPS studio signs the host into a private project, runs the public walkthrough, renders progress and returns a valid PowerPoint that survives a new sign-in. | Open the deployed `/research`, use an approved public test site and repeat AC-1, AC-3 and AC-4. | AC-9 | Host confirms and downloads the reviewed PowerPoint selection | The file contains only the selected saved text, URLs and screenshot bytes, plus any text the host explicitly adds. The order and slide count match the reviewed content groups and any explicit host addition slides. | AC-11 | Host attempts to confirm an empty or invalid PowerPoint selection | An empty or stale selection and any item outside the selected walkthrough are rejected without a new export. Check the saved list and previous download hash, then correct the selection in the normal UI and confirm it. | fixture |

Out of scope: Signing in to third-party sites, submitting site forms, cross-origin navigation, and modifying the approved website.

Invariants: Capture approval and export confirmation are separate host actions. Export content comes from its saved walkthrough items and explicitly entered host text. Selecting a screenshot includes the reviewed capture as an image, with any text already visible in its pixels. The stored selection, artifact bytes, capture provenance and owner/project/walkthrough identity survive retries and fresh sign-in. Capture results and screenshots remain private. The existing presenter deck path continues to use its own approval and saved revision.
