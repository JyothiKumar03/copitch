# Contract: Private pitch studio (module 1)

Owner decisions pending: Confirm the public launch language list after the proposed English/Hindi live checks. Production voice spend limits, customer data retention and authorization for public deployment remain open.
Source: docs/product.md#module-1-customer-journey, docs/architecture.md

| ID | Actor action | Observable outcome | Check (entry point + exact command or click path) | Required evidence |
|----|--------------|--------------------|---------------------------------------------------|-------------------|
| AC-1 | Sign in and create a project | The private studio opens with chat and files in the center and the agent on the right on desktop. The project appears in the signed-in project list. | Sign in from the app home, choose New project, open the studio, then return to Projects and reopen that entry. | fixture |
| AC-2 | Open another customer's pitch URL | The request is denied, and the other customer's project and pitch are absent from the signed-in project list. | Save the URL of account A’s pitch. Sign in as B, open Projects, and request A’s saved pitch URL using B’s credentials. | fixture |
| AC-3 | Switch languages while briefing the agent | The microphone stays active. The transcript preserves the original utterance and each spoken reply follows the latest language unless the host explicitly sets a preference. A spoken interruption cuts off the reply. | In one studio voice session speak English, then Telugu, then English again. Compare the saved transcript and actual spoken reply for each turn. Repeat with a mixed-language interruption on a physical microphone. | live |
| AC-4 | Choose files-only research and approve a brief | The studio displays the confirmed scope, runs one job and limits retrieval to the attached material. | Attach a CSV, select My materials only, submit a brief, approve the displayed scope twice and inspect the job count and recorded outbound searches. | fixture |
| AC-5 | Approve research and ask for progress | The microphone closes after the acknowledgement. Chat shows progress while the same job continues. | Start approved research in the studio, confirm the browser releases the microphone, then ask for progress in chat. Compare the job and brief IDs before and after the question. | live |
| AC-6 | Select the completed context file | The private viewer opens the saved context, previews the cited chart and exposes Markdown source and download for that revision. | In the studio open a completed fixture pitch with comparable source data. Select context.md in chat, inspect chart values and evidence references, switch to Markdown, download the file and compare to the displayed source.  | fixture |
| AC-7 | Close the browser during research and return | The signed-in host finds the same project, one research result and its saved context. Microphone capture requires a fresh gesture. | Start an approved job, close the tab, restart its worker, then sign in from a fresh browser. Reopen the project, wait for the result and open context.md. Check saved sources, revision and job count. | fixture |
| AC-8 | Deny microphone permission | The studio offers typed input and the host can finish the same brief, approve research and obtain the pitch. | In a fresh studio deny the microphone prompt, enter a brief, confirm the scope and open the completed file. | fixture |
| AC-9 | Open a pitch with unsupported chart data | Uncomparable values are withheld, and the remaining pitch and evidence gaps are readable. | In the studio approve a fixture with mixed units for the proposed comparison, open the generated pitch and compare its claims and chart area with the source rows. | fixture |
| AC-10 | Return to the hosted service | The account owner can complete the journey at its HTTPS address, sign out and sign back in from another browser to reopen the same context. | After owner-approved deployment, open the hosted home page, sign in, create a project, brief by voice, approve, download context.md, then sign in on a second device and reopen the same revision. | deployed |
| AC-11 | Say “pitch about myself” and greet again midway | The studio follows the conversation and asks one specific follow-up. A follow-up question from the host does not become a factual note or listener decision. | In a new project, start with a greeting, ask for a pitch about yourself, provide one fact, greet again, and ask what the audience should do. Inspect the next reply and proposed plan. | live |
| AC-12 | Interrupt the spoken proposal, then approve the current plan | An interrupted readback confers no spoken approval. A deliberate approval of the current plan starts a single job. | Interrupt the readback, say yes, and check that no job exists. Read the updated plan and click Start research twice. Check that only its reviewed revision has a job. | live |
| AC-13 | Approve a source that provides no usable evidence | The studio asks for another source or an example. The revision has no pitch file. | Use an empty or unavailable approved public source and no other material, approve, wait for Needs input, then reopen the project. Check that no new pitch is available. | live |

Out of scope: Public live presentation, guided browser walkthrough, payment-plan selection and general chart messages outside the private context artifact.
Invariants: Account and project isolation, explicit source-scope approval, evidence provenance, revision identity, one durable job per approved brief, and recoverable host-only artifacts.
